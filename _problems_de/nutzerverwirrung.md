## Description
Nutzerverwirrung ist ein häufiges Problem in Softwaresystemen. Sie tritt auf, wenn Endnutzer unterschiedliches Verhalten für das erleben, was identische Operationen sein sollten. Dies kann zu einer Reihe von Problemen führen, einschließlich Frustration, Vertrauensverlust in das System und erheblicher Frustration für das Entwicklungsteam. Nutzerverwirrung ist oft ein Zeichen eines schlecht designten Systems mit hohem Grad an inkonsistentem Verhalten.

## Indicators ⟡
- Das Support-Team erhält konstant Fragen von Nutzern dazu, wie das System zu nutzen ist.
- Nutzer nutzen das System nicht auf die Art, wie es beabsichtigt war.
- Nutzer machen viele Fehler bei der Nutzung des Systems.
- Nutzer sind mit dem System nicht zufrieden.

## Symptoms ▲

- [Nutzerfrustration](nutzerfrustration.md)
<br/>  Nutzer, die durch inkonsistentes Systemverhalten verwirrt sind, werden mit dem Produkt frustriert.
- [Erosion des Nutzervertrauens](erosion-des-nutzervertrauens.md)
<br/>  Wenn Nutzer Systemverhalten nicht vorhersagen können, verlieren sie das Vertrauen in die Zuverlässigkeit des Systems.
- [Negatives Nutzerfeedback](negatives-nutzerfeedback.md)
<br/>  Verwirrte Nutzer geben negatives Feedback zur Nutzbarkeit und dem Design des Systems.
- [Kundenunzufriedenheit](kundenunzufriedenheit.md)
<br/>  Anhaltende Verwirrung führt zu allgemeiner Kundenunzufriedenheit mit dem Produkt.

## Causes ▼

- [Inkonsistentes Verhalten](inkonsistentes-verhalten.md)
<br/>  Wenn sich das System für das, was identische Operationen sein sollten, unterschiedlich verhält, werden Nutzer über das erwartete Verhalten verwirrt.
- [Schlechtes Nutzererlebnis (UX-Design)](schlechtes-nutzererlebnis-ux-design.md)
<br/>  Schlecht designte Schnittstellen mit unklarer Navigation und Workflows verwirren Nutzer direkt.
- [Inkonsistente Namenskonventionen](inkonsistente-namenskonventionen.md)
<br/>  Inkonsistente Beschriftungen und Terminologie im gesamten System verwirren Nutzer, die kein kohärentes mentales Modell bilden können.
- [Schlechte Dokumentation](schlechte-dokumentation.md)
<br/>  Der Mangel an klarer Dokumentation oder Hilferessourcen lässt Nutzer ohne Anleitung, wenn sie auf verwirrendes Verhalten stoßen.

## Detection Methods ○
- **Usability-Tests:** Nutzung von Usability-Tests zur Identifikation von Bereichen des Systems, die für Nutzer verwirrend sind.
- **Nutzerfeedback:** Anhörung von Nutzerfeedback zur Identifikation von Bereichen des Systems, die Verwirrung verursachen.
- **Support-Ticket-Analyse:** Analyse von Support-Tickets zur Identifikation häufiger Fragen und Probleme.
- **A/B-Tests:** Nutzung von A/B-Tests zum Vergleich verschiedener UI-Versionen, um zu sehen, welche für Nutzer weniger verwirrend ist.

## Examples
Eine E-Commerce-Website hat einen sehr verwirrenden Checkout-Flow. Die Nutzer sind sich nicht sicher, was sie tun sollen, und machen viele Fehler. Infolgedessen verliert das Unternehmen viele Verkäufe. Das Problem könnte gelöst werden, indem der Checkout-Flow neu gestaltet wird, um intuitiver und einfacher zu nutzen zu sein.
